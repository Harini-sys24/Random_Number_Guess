# Lucky Number

A simple number-guessing game built with HTML, CSS, and vanilla JavaScript. The game chooses a number from 1 to 100 and gives a higher-or-lower hint after each valid guess.

## Play

Open `index.html` in a web browser. No installation, server, or build step is required.

Enter a whole number from 1 to 100 and select **Take a guess**. The game counts valid guesses and ends when you find the secret number. Select **New game** to start over with a new number.

## Project files

- `index.html` — game structure and controls
- `style.css` — responsive layout and visual styling
- `script.js` — random number selection, guess validation, hints, and reset behavior

The page loads fonts from Google Fonts, so those fonts require an internet connection; the game itself runs locally in the browser.
